# Catch & Crunch Concept Demo

This is a one-page sales demo built from photos supplied by Justin.

## Important
- Not the restaurant's official website
- No online checkout
- No POS integration
- No order transmission
- No customer data collection
- Menu prices shown are selected items transcribed from photographed menu boards and should be confirmed by the owner before launch

## Deploy
Upload the repository to GitHub and import it into Vercel as a static site. No build command is required.
